# Adaptor Signatures (Conduition) — structure-only reference

## Structural pattern demonstrated

This article takes one primitive (adaptor signatures) and frames it as a small set of independent puzzle-like questions — riddles — each examining a distinct facet of the primitive's behavior (edge cases, variant constructions, failure modes). The riddles are enumerated up front so the reader holds the whole map before descending into any one question. Each riddle then gets its own self-contained section that resolves it without forward references to the others. A short synthesis at the end (optional) ties the resolutions together, but the sections are engineered to stand alone. The structural payoff: a reader can grasp the primitive holistically by watching several independent angles get resolved in parallel, rather than following a single linear derivation.

## Why voice is NOT imported

Conduition's voice is blog-performative (aimed at Bitcoin-community engagement). Specific tells: prior-art paragraphs, "Let's dive in" openers, self-deprecating asides that perform personality rather than explain. None of these ports to explanatory clarity; the skill should extract the skeleton only.

## How to apply this pattern in a concept note

This is the structural reference for the **Riddles** template. Use when one primitive has 2-3 *independent* puzzle-like questions worth examining (edge cases, variant behaviors, failure modes). Enumerate the riddles upfront; resolve each in its own section; close with a brief synthesis if useful. Do NOT port conduition's voice — the skeleton ports, the tone does not.
